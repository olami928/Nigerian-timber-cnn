# Timber ID (web + Android)

Static web app and Capacitor-packaged Android project for the Nigerian Timber Species Identification research prototype.

- **Model:** ShuffleNetV2 ONNX export (`app/model/model.onnx`, 29 classes, fixed order in `class_names.json`).
- **Inference:** 100% on-device/browser. 6×8 grid (48 patches), 112×112 resize, ImageNet normalization, per-patch softmax, majority vote with mean-probability tie-break, patch-agreement reporting. Blur retake uses Laplacian variance (`min_sharpness` from preprocess config). **No model weights/architecture/class order/preprocessing logic changed.**
- **Data:** Species names/uses loaded locally from generated `public/species.json` (built from `configs/species.csv`, `configs/species_enduse.json`, `data/manifest.csv`). Documented uses only (primary/secondary); no fabricated uses.
- **Offline design:** relative asset paths, bundled model + ONNX Runtime Web WASM + CSS/JS/JSON/icons (data URI) — no external CDNs/APIs/fonts required at runtime.

> Research prototype. Reported independent-specimen image-level accuracy was low (12.1% ShuffleNetV2, 11.3% ResNet18 on 611 test images from 14 species). Not for legal, purchasing, import/export, or structural-grading decisions.

```sh

python3 -m http.server 8765 --bind 127.0.0.1 --directory public
# open http://127.0.0.1:8765/
```

Build output: `app/public/` (bundled JS, copied `model.onnx`, `class_names.json`, `preprocess_config.json`, generated offline `species.json`, and `ort/*.wasm|mjs`).

## Offline species database (`species.json`)

`app/public/species.json` is the app’s bundled, offline species reference (no runtime fetch of source configs). It is generated by `app/build-species-data.mjs` (invoked by `npm run build`) from authoritative sources:

- `configs/species.csv` — canonical IDs/slugs/local names/botanical names/wood type and class order (must match model `class_names.json`)
- `configs/species_enduse.json` — verified English name (if present), documented uses, sources, status/notes/metadata
- `data/manifest.csv` — per-species `training_specimens` counts

Generation rules (preserved): only `primary`/`secondary` documented uses are included; empty/missing uses remain empty (UI hides the uses section). Documented uses/sources are literature/database records, not image/model predictions. `status`/`notes` are retained under `provenance` for traceability (internal metadata) and not fabricated; canonical IDs/order are validated.

To regenerate after changing any source file:
```sh
cd app
npm run build            # regenerates species.json, copies model/WASM, rebuilds bundle
# sync packaged Android assets:
cp -R public/. android/app/src/main/assets/public/
# or, on a machine with Capacitor tooling/SDK configured:
# npx cap sync android
```
Verify `public/species.json` and `android/app/src/main/assets/public/species.json` match and contain 29 species in canonical order.

### Prerequisites (build machine)

- Node.js + npm
- **JDK 17** (`JAVA_HOME` set)
- **Android SDK** (`ANDROID_HOME`/`ANDROID_SDK_ROOT` set), with:
  - Command-line tools / `sdkmanager`
  - Platform Tools (`adb`)
  - Build-Tools (matching project; see `app/android/variables.gradle`)
  - Android platform `compileSdkVersion` (34)
- A real Android device (USB debugging) or emulator for install/testing

Create `app/android/local.properties` if needed:
```
sdk.dir=/path/to/android/sdk
```

### Build debug APK

```sh
cd app/android
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Install: `adb install -r app/build/outputs/apk/debug/app-debug.apk`

### Create a signed release APK (instructions)

1. Generate a keystore (keep it private, do not commit):
   ```sh
   keytool -genkeypair -v -keystore timberid-release.keystore -alias timberid \
     -keyalg RSA -keysize 2048 -validity 10000
   ```
2. Create `app/android/keystore.properties` (do not commit):
   ```
   storePassword=<password>
   keyPassword=<password>
   keyAlias=timberid
   storeFile=/absolute/path/to/timberid-release.keystore
   ```
3. Add signing config in `app/android/app/build.gradle` (release `buildTypes`) to load `keystore.properties` and set `signingConfig`.
4. Build:
   ```sh
   cd app/android
   ./gradlew assembleRelease
   # APK: app/build/outputs/apk/release/app-release.apk
   ```

### Offline & permissions notes

- Manifest removes INTERNET and requests camera/media read permissions for capture/gallery (WebView file inputs and Capacitor Camera plugin). FileProvider configured for camera captures.
- All inference assets are packaged under `android/app/src/main/assets/public/` (model, WASM, JSON, JS/CSS). Verify on-device in airplane mode before claiming fully offline operation.

## Validation checklist (run on a build machine/device)

- **Parity (≥20 test images):** compare predicted class, per-patch predictions, aggregated prediction, vote counts, agreement across original Python, web, and APK.
- **Offline (real device, airplane mode):** install, launch, navigate all screens, camera capture, gallery select, run inference, view species info, close/reopen and repeat — all without network/downloads.
- **UI:** small/large screens, portrait, touch, previews, loading/errors, long names, large photos, EXIF orientation.
